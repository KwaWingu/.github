# KwaWingu

**Software for East African tourism and hospitality.**
Booking engines, payments and WhatsApp commerce for tour operators, lodges and restaurants. Built in Arusha, Tanzania.

🌍 [kwawingu.com](https://kwawingu.com) · ✉️ info@kwawingu.com

---

### Products

| Product | What it does |
|---|---|
| **KwaWingu Tours** | Booking platform for safari and tour operators, with a versioned public developer API and OTA availability sync (OCTO) |
| **KwaWingu Stay** | Property management and direct booking for lodges, camps and hotels |
| **KwaWingu Dine** | WhatsApp-native AI ordering and payments for restaurants |
| **KwaWingu Rentals** | Bookings and availability for rental businesses |
| **KwaWingu QR** | QR code tools for hospitality businesses |

All products share one identity, billing and payments layer, with mobile money and card payments settled directly to each business.

### Open source

- **[Mobile-Payments-Library](https://github.com/KwaWingu/Mobile-Payments-Library)**: Java 21 SDK for Tanzanian mobile money (M-Pesa, Airtel Money, HaloPesa, Mixx by Yas)
- **[kw-wp-plugin](https://github.com/KwaWingu/kw-wp-plugin)**: WordPress plugin that turns a KwaWingu Tours catalogue into an SEO-ready tour-operator website

### Built with

Java 21 · Spring Boot · GraphQL · PostgreSQL · Next.js · TypeScript · Cloudflare · WhatsApp Business API
